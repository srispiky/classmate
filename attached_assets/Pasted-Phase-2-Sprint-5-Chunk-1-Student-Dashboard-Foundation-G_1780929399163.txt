# Architecture Rules

Maintain project architecture standards.

Controllers:

* validation only
* service invocation only
* response mapping only

Repositories:

* database access only

Services:

* business logic only

Policies:

* authorization only

Validators:

* ownership and scope decisions only

Authorization logic is NOT allowed in:

* controllers
* repositories

Do not introduce new authorization patterns.

Reuse existing ownership infrastructure.

# Student Ownership Requirements

Student visibility is limited to:

* enrolled courses only

Use existing:

* ScopeContext
* student ownership filtering
* CourseScopePolicy
* ownership validators

Do not duplicate ownership logic.

Do not create dashboard-specific ownership rules.

# Dashboard Endpoint

Create a student dashboard endpoint.

Suggested route:

GET /student/dashboard

Use existing route naming conventions if different.

The endpoint must return a dashboard summary object.

# Dashboard Response

Include:

## Student Summary

* studentId
* displayName

## Course Summary

* activeCourseCount

## Assignment Summary

* totalAssignments
* pendingAssignments

Assignments must be limited to enrolled courses.

## Assessment Summary

* totalAssessments
* upcomingAssessments

Assessments must be limited to enrolled courses.

## Announcement Summary

* unreadAnnouncements

Announcements must be limited to enrolled courses.

## Notes Summary

* availableNotes

Notes must be limited to enrolled courses.
