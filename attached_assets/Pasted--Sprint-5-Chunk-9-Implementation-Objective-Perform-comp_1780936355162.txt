## Objective

Perform comprehensive Student Portal Hardening across all Sprint 5 functionality.

This chunk focuses on security validation, ownership regression testing, authorization verification, performance validation, API contract validation, and edge-case testing.

## Security Validation

Perform comprehensive authorization review.

Validate:

### Authentication

Unauthenticated requests:

* return 401
* never expose data
* never bypass middleware

---

### Role Enforcement

Validate:

* student endpoints reject teacher users
* student endpoints reject parent users
* student endpoints reject unauthorized roles

Expected:

403 Forbidden

---

### Ownership Enforcement

Validate:

Student cannot access:

* non-enrolled courses
* non-enrolled assignments
* non-enrolled assessments
* non-enrolled announcements
* non-enrolled notes

Expected:

404 or ownership denial according to platform standards

---

### IDOR Validation

Attempt direct access using identifiers from:

* other students
* other courses
* unrelated resources

Verify:

* no data exposure
* no metadata leakage
* no ownership bypass

---

### ScopeContext Validation

Verify every endpoint derives access through ScopeContext.

Validate:

* enrolledCourseIds respected
* studentId respected
* ownership filters consistently applied
