# Sprint 7 Chunk 3 — Assessment Management + Missing PATCH Endpoint

Act as a Principal Full-Stack Engineer working on the Classmate platform.

Implement Sprint 7 Chunk 3 completely.

GOAL

Make Assessment Management fully usable for teachers.

This chunk includes BOTH backend and frontend work.

Before making changes:

1. Review current assessments frontend.
2. Review backend route implementation in assessments.ts.
3. Review OpenAPI contract.
4. Review generated API hooks.
5. Follow all patterns established in Sprint 7 Chunks 1 and 2.

IMPORTANT

The Teacher Portal audit identified that:

* PATCH /assessments/:id does not exist
* OpenAPI has no PATCH entry
* Generated hooks do not exist
* Assessments are effectively write-once

This must be fixed end-to-end.

## Backend Deliverables

### Add PATCH /assessments/:id

Implement:

* Layer 1 authorization
* Layer 2 scope filtering
* Layer 3 ownership validation
* Audit field updates (`updatedAt`, `updatedBy`)
* Soft-delete protection
* Validation

Teachers must only update assessments they own.

Support updates to:

* score
* strengths
* weaknesses
* notes/feedback (if supported by schema)

Do NOT allow ownership transfer.
