# Endpoints

Implement:

## List Assignments

GET /student/assignments

Returns assignments visible to the authenticated student.

Student must only see assignments from enrolled courses.

---

## Assignment Detail

GET /student/assignments/{assignmentId}

Returns assignment details.

Access must be denied when:

* assignment does not exist
* assignment belongs to a non-enrolled course
* assignment is soft deleted
