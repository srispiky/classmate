OBJECTIVE
--------------------------------------------------

Establish production-grade observability.

- basic logs only

- limited visibility into failures

Implement the observability foundation.

--------------------------------------------------

Review:

- console.log usage
- console.error usage
- route logging
- startup logging
- backup logging

Identify:

- duplicated logs
- missing logs
- inconsistent formats

Document findings.

--------------------------------------------------
PART 2 — STRUCTURED LOGGING
--------------------------------------------------

Implement:

Centralized logging utility.

Requirements:

- timestamp
- severity
- component
- operation
- correlation id support

Levels:

- DEBUG
- INFO
- WARN
- ERROR

Replace:

ad-hoc console logging.

Do not change business logic.

--------------------------------------------------
PART 3 — REQUEST CORRELATION
--------------------------------------------------

Implement:

Request ID middleware.

Requirements:

Every request receives:

- requestId

Request ID must flow through:

- route handlers
- services
- error logging

Include requestId in logs.

--------------------------------------------------

Implement metrics collection.

Track:

- request count
- request duration
- error count
- auth failures
- database query failures
- backup failures

Metrics must be centralized.
