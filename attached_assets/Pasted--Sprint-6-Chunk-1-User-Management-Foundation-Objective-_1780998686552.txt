# Sprint 6 — Chunk 1: User Management Foundation

## Objective

Implement a production-ready User Management module.

This module will become the authoritative mechanism for creating and managing:

* Admin accounts
* Teacher accounts
* Student accounts
* Parent accounts

The goal is to eliminate manual database user provisioning.

---

## Architecture Requirements

Follow existing architecture standards.

### Controllers

Responsibilities:

* request validation
* service invocation
* response mapping

No business logic.

---

### Services

Responsibilities:

* user creation
* password management
* account activation/deactivation
* role assignment

---

### Repositories

Responsibilities:

* database access only

---

### Policies

Responsibilities:

* authorization only

---

## Database Review

Review existing tables:

* users
* roles
* permissions
* role_permissions
* user_roles

Determine whether:

* users.role remains authoritative
* user_roles becomes authoritative

Provide recommendation.

Do not introduce dual authorization models.

## Endpoints

### List Users

```http
GET /api/users
```

Authorization:

```ts
requireRole("admin")
```

Return:

* id
* username
* displayName
* role
* isActive
* createdAt

Exclude:

* passwordHash

---

### Create User

```http
POST /api/users
```

Authorization:

```ts
requireRole("admin")
```

Request:

```json
{
  "username": "teacher1",
  "displayName": "Teacher One",
  "password": "temporaryPassword",
  "role": "teacher"
}
```

Requirements:

* unique username validation
* password hashing
* audit field population

---

### Get User

```http
GET /api/users/{userId}
```

Authorization:

```ts
requireRole("admin")
```

---

### Update User

```http
PATCH /api/users/{userId}
```

Support:

* displayName
* role
* isActive

Do not allow direct password updates.

---

### Reset Password

```http
POST /api/users/{userId}/reset-password
```

Authorization:

```ts
requireRole("admin")
```

Requirements:

* generate new password hash
* update audit fields
