# Endpoints

Implement student course endpoints.

## List Courses

GET /student/courses

Returns all courses visible to the authenticated student.

Student must only see enrolled courses.

## Get Course

GET /student/courses/{courseId}

Returns details for a single enrolled course.

Access must be denied if:

* course does not exist
* student is not enrolled
* enrollment is inactive

# Response Requirements

* description
* teacherId
* enrollmentStatus

Course detail should include:

* teacherId

Use existing DTO conventions.
