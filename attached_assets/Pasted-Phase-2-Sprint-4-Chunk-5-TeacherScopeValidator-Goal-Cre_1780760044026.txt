* CourseScopePolicy

# Core Authorization Rules

Admin

* Global access

Teacher

* Access only owned courses

Rule:

```ts
courseId IN scope.ownedCourseIds
```

Student

* Access only enrolled courses

Rule:

```ts
courseId IN scope.enrolledCourseIds
```

Parent

* Access only child courses

Rule:

```ts
courseId IN scope.childCourseIds
```

# Primary Function

Create:

```ts
canAccessCourse(
  scope: ScopeContext,
  courseId: string
): boolean
```

Behavior:

Admin

```ts
true
```

Teacher

```ts
scope.ownedCourseIds.includes(courseId)
```

Student

```ts
scope.enrolledCourseIds.includes(courseId)
```

Parent

```ts
scope.childCourseIds.includes(courseId)
```

Otherwise

```ts
false
```

# Validation Helper

Create:

```ts
validateCourseAccess(
  scope: ScopeContext,
  courseId: string
): void
```

Behavior:

* Calls canAccessCourse()
* Throws AuthorizationError when access denied
* Reuse existing authorization exception patterns

Do not introduce new error types.
