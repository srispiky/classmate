SECTION 2
Teacher Boundary Validation
===========================

Verify:

Teacher A

owns:

```text
Course A
Course B
```

Teacher B

owns:

```text
Course C
Course D
```

Validate:

Teacher A cannot:

* view Course C
* update Course C
* delete Course C
* view Course C assignments
* view Course C assessments
* view Course C notes
* view Course C announcements
* manage Course C enrollments

Expected:

```http
403 Forbidden
```

for every unauthorized operation.
