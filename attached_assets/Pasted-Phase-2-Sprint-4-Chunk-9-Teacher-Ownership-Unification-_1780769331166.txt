Phase 2 – Sprint 4

Chunk 9 – Teacher Ownership Unification

# Goal

Remove all remaining Teacher Global Access behavior and fully transition the platform to Teacher Ownership-Based Access.

After this chunk:

Admin

* Global access

Teacher

* Access only resources associated with owned courses

Student

* Existing access rules remain unchanged

Parent

* Existing access rules remain unchanged

# Current State

Course ownership infrastructure already exists:

* ScopeContext.teacherId
* ScopeContext.ownedCourseIds
* TeacherScopeValidator
* CourseScopePolicy

Courses already enforce ownership boundaries.

However, some resource policies still allow:

```text
Teacher = Global Access
```

This chunk removes that behavior.

# Objectives

1. Unify teacher ownership model
2. Refactor resource policies
3. Enforce course ownership everywhere
4. Preserve student access
5. Preserve parent access
6. Add regression tests
7. Add IDOR tests

Review any additional resource policies that currently contain:

# Authorization Target Model

Admin

* Global access

Teacher

* Existing child-course access

# Teacher Ownership Rule

Resource access must be determined through:

```ts
scope.ownedCourseIds
```

loaded during authentication.

No additional ownership queries during authorization.

No runtime ownership resolution.

```ts

CourseScopePolicy
```

```ts

```

duplicated throughout policies.

Centralize authorization decisions.
