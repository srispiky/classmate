# Endpoints

Implement:

## List Assessments

GET /student/assessments

Returns assessments visible to the authenticated student.

Student must only see assessments from enrolled courses.

---

## Assessment Detail

GET /student/assessments/{assessmentId}

Returns assessment details.

Access must be denied when:

* assessment does not exist
* assessment belongs to a non-enrolled course
* assessment is soft deleted
