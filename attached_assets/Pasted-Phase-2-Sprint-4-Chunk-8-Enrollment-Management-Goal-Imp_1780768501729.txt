# Endpoints

Implement:

```http
POST /courses/:courseId/enrollments
```

and

```http
DELETE /courses/:courseId/enrollments/:studentId
```

Use existing routing conventions.

# Authorization Rules

Admin

* Can enroll students into any course
* Can remove students from any course

Teacher

* Can enroll students only into owned courses
* Can remove students only from owned courses

Student

* Forbidden

Parent

* Forbidden

# Duplicate Enrollment Handling

Reject:

```text

```

Use existing application error patterns.

Do not create duplicate rows.

# Enrollment Removal

Preferred behavior:

Soft unenrollment.

Update:

```sql
is_active = false

updated_at
updated_by
```

instead of deleting rows.

Historical enrollment records must be preserved.
