--------------------------------------------------
OBJECTIVE
--------------------------------------------------

Fix dashboard privacy and correctness.

Current audit finding:

Teachers see platform-wide:

- total students
- total courses
- total assignments
- total assessments
- recent activity
- grade distribution
- top performers

The dashboard ignores teacher ownership.

Teachers must only see data from their own courses.

Admins continue to see global data.

--------------------------------------------------
PART 1 — DASHBOARD SUMMARY
--------------------------------------------------

Review:

GET /dashboard/summary

Current behavior:

Queries:

- studentsTable
- coursesTable
- assignmentsTable
- assessmentsTable

without scope filtering.

Implement:

Admin:
- unchanged

Teacher:
- only own courses
- only students enrolled in own courses
- only assignments belonging to own courses
- only assessments belonging to own courses

Verify:

Teacher A cannot see Teacher B metrics.
